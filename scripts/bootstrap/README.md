# Bootstrap

Bootstrap Google nie jest dostarczany w `0.1.0-alpha.1`. Brak bezpiecznego,
wspieranego przepływu o minimalnym zakresie; implementowanie znanych obejść
naruszyłoby warunki audytu. Nie umieszczaj tu sekretów.

The Google bootstrap is intentionally BLOCKED. A future helper must satisfy
`docs/AUTHENTICATION.md`, remain outside HA runtime and pass manual E2E review.
